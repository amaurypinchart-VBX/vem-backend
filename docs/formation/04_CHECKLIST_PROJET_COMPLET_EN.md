# ✅ "Complete project" checklist (VEM)

> Tick at each stage. A complete project gives a complete briefing, a correct calendar and a clean handover.
> In brackets: where to enter it in VEM. VEM's screens are in French: names are given exactly as they appear, with the English meaning where useful.

## 1. Before « ✅ Devis validé » (quote approved)

- [ ] **Client** existing or created only once (🏢 Clients): name, **company e-mail**, phone, address, VAT number
- [ ] **Client contact** with name, e-mail, phone, **job title** and ★ main contact (🏢 Clients › ✏️ Modifier)
- [ ] **Internal number** in Viewbox format: 4 digits + 4 to 6 letters + VIE (✏️ Modifier › N° Interne)
- [ ] Readable project **name**
- [ ] Full **address**, "street number, postcode City" (the city after the last comma)
- [ ] **Installation dates** with times (start and end)
- [ ] **Dismantling dates** if known
- [ ] **Description / Instructions spéciales** (number of Viewbox, modules, access)
- [ ] **🌐 Notes globales du projet** (global project notes)
- [ ] Quote and drawings in **📁 Fichiers** (⬆️ Ajouter, or an email with the internal number)
- [ ] **Status**: 📝 Devis à valider (quote to approve) → ✅ Devis validé (quote approved)
- [ ] Project created by email: **checked** (dates, client ≠ « ⚠️ Client à confirmer », address)

## 2. Before departure (briefing)

- [ ] **Status** 🔧 En préparation (in preparation)
- [ ] **Team** complete, with each person's role and phase (👥 Équipe tab)
- [ ] Phone number entered for every member (👥 Équipe › member's record)
- [ ] **Trucks and machines**: type, plates, driver, places, loading and arrival dates (🚛 Logistique tab)
- [ ] **Travel** for each member, per phase, ticket attached (✈️ Bookings tab)
- [ ] **Hotels** with all occupants, reference and confirmation (✈️ Bookings tab)
- [ ] **Drafts created by email** approved (trucks, hotels, trips)
- [ ] **🔨 Notes installation** and **🔧 Notes démontage** (installation / dismantling notes)
- [ ] **Checklists configured**: preparation (📋 Infos), installation and dismantling (📓 Daily Reports)
- [ ] **Preparation checklist** filled in
- [ ] **Briefing**: 🎨 Studio › 🪄 Auto-générer › proofread › 💾 Sauvegarder › 📄 PDF sent to the team
- [ ] Information and bookings sent to each member (📤 in 👥 Équipe)

## 3. During installation (every day)

- [ ] **Status** 📍 Sur site (on site), then 🏗️ En installation (installing)
- [ ] **Installation checklist** filled in during the day (photos and comments)
- [ ] **Daily report** of the day: workers, weather, ⏱️ hours per task, log, photos, checklist attached
- [ ] Daily report sent if needed (client unticked if the report is internal)
- [ ] Trucks set to 🟢 Livré (delivered) on arrival

## 4. Before the handover

- [ ] **Installation checklist** with no « À vérifier » (to check) point, critical points OK or N.A., ✅ approved
- [ ] Client record with an **e-mail** (recipient of the signed PDF)
- [ ] Handover created from **the project's 🧾 Handover tab**, one zone per inspected point, photos
- [ ] **📋 Étendue des travaux** (scope of work) (✏️ Modifier on the handover)
- [ ] Signature on site **or** 🔗 link sent to the client
- [ ] PDF downloaded **from the opened record** (👁️ Ouvrir › 📄 PDF) or sent (📤 Envoyer)
- [ ] **Status** 🧾 Handover OK (it does not change by itself)

## 5. Dismantling and closing

- [ ] **Status** 🔨 Démontage (dismantling)
- [ ] **Dismantling checklist** filled in
- [ ] Daily reports of the dismantling
- [ ] Vehicles set to ⚫ Retour entrepôt (back at warehouse)
- [ ] **📊 Rapport IA** (AI report) generated (Tâches section unticked)
- [ ] **📁 Fichiers** tidied: duplicate PDFs and email logos deleted
- [ ] **Status** 🎉 Terminé (completed)
- [ ] Nothing deleted: an abandoned project is **archived** (📦), never deleted
