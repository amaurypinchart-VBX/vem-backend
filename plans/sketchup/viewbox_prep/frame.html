🏗 Structure de la box

Les profils (barres) dessinés dans ce composant de box, relevés automatiquement. Une ligne par composant de profil : ton choix vaut pour toutes les box de ce type. Vérifie le rôle (rive, traverse, poteau…) et la section (ex. UPN 200, RHS 120x60x4) ; laisse la section vide si elle n'est pas dans la liste : VEM la mesure sur la coupe. « Non porteur » retire la pièce du calcul (rail, habillage, cornière de finition…). Rien n'est modifié dans le dessin.
